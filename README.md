## 常见问题

**西雅图和洛杉矶 DC-02 选哪个？**

两边都不是优化线路。洛杉矶 DC-02 有 BGP 优化，官方 FAQ 口径对电信、联通更友好一些；西雅图的优势是三网双程直连、电信 163 表现稳定。选之前用两个机房的测试 IP 各 ping 一晚，比看任何对比表都直接。

**1Gbps 端口能跑满吗？**

国内方向跑不满，晚高峰尤其明显，瓶颈在国内出口带宽。欧美方向测速正常。

**流量超了怎么办？**

超额部分需要额外付费，具体单价以下单时的套餐说明为准。跑流媒体或者做下载中转的，先把月流量算清楚再选档。

**能装 Windows 吗？**

按官方活动页的表述，可选系统是 Linux 发行版加自定义 ISO，没有把 Windows 列为标准镜像。需要 Windows 的话开工单问清楚授权和费用，别默认它能直接用。
